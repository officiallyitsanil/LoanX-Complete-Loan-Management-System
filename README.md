# LoanX – Complete Digital Lending Software

### Launch Your Own Digital Lending Platform

LoanX is a comprehensive digital lending software solution built with Flutter and Laravel. It provides a borrower mobile application, administration dashboard, loan management backend and customizable public website.

**Developed by SiteShieldSecurity**

## Product Overview

- Flutter Android Borrower Application
- Laravel Backend & REST APIs
- Advanced Admin Dashboard
- Customizable Website
- Loan Origination System (LOS)
- Loan Management System (LMS)

## Key Features

### Borrower Mobile Application

- Mobile registration and OTP verification
- Borrower dashboard
- Loan application management
- Credit limit interface
- KYC and document management
- EMI and repayment tracking
- Loan history and notifications

### Admin Panel

- Loan management dashboard
- Borrower management
- Loan application processing
- Loan underwriting workflow
- Loan products and schemes
- Collections and overdue management
- Financial transaction management
- AutoPay mandate management
- Support and grievance management
- Role-based administration

### Technology Stack

- Flutter & Dart
- PHP & Laravel
- MariaDB / MySQL
- REST APIs
- HTML, CSS and JavaScript
