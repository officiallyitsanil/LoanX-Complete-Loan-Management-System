LoanX Digital Lending Platform

Welcome to the official full documentation for LoanX — the complete end-to-end digital lending, microfinance, and personal loan ecosystem with paperless DigiLocker KYC, Video KYC, e-NACH/UPI AutoPay, and an automated underwriting engine.

Laravel 10/11 Flutter 3.35+ MySQL 8.0 AES-256 / Passport OAuth Aadhaar e-Sign & KFS
1. System Architecture & Overview

LoanX is engineered specifically for Regulated Entities (NBFCs), digital lending service providers, banks, and fintech startups. Unlike legacy generic wallet or remittance scripts, LoanX provides a dedicated, legally compliant loan disbursal and automated recovery infrastructure.

Enterprise Admin Panel

Built with Laravel 10/11, providing pipeline underwriting, credit risk management, loan sanctioning, and employee role-based access control.

Cross-Platform Mobile App

High-performance Flutter application for Android and iOS with paperless loan onboarding, loan calculators, and instant drawdown.

Key Fact Statement (KFS)

Automated generation of RBI-mandated Key Fact Statements disclosing APR, processing fees, net disbursals, and Aadhaar OTP e-Signatures.

e-NACH & UPI AutoPay

Real-time automated mandate authentication through Debit Card, NetBanking, and UPI 2.0 with scheduled automatic EMI debits.

RBI Digital Lending & Google Play Compliant: LoanX is built strictly respecting digital lending directives. The user application requests zero invasive permissions (no SMS access, no call logs, no contact harvesting, no external gallery snooping), ensuring full compliance with Google Play Store policies and Google Play Protect.
2. Platform Capabilities & Features

Key Lending Modules

  • Instant Credit Limit Engine: Algorithmic evaluation of customer score, salary brackets, and previous repayment performance.
  • Digital Paperless KYC: Instant Aadhaar & PAN verification via DigiLocker API simulation, selfie match, and Live Video KYC with underwriting officers.
  • Aadhaar OTP e-Sign: Legally binding digital loan contract agreement generated dynamically upon loan approval.
  • Instant Bank Disbursal: Sanctioned credit line funds transferred directly to verified bank accounts via IMPS/NEFT rails.
  • Flexible Repayment Tenures: Configurable schemes (1, 3, 6, 9, 12, up to 36 months) with transparent reducing or flat APR calculation.
  • Automated Overdue & Penalty Engine: Real-time daily overdue calculation with configurable grace periods and penal interest per day.
  • No Dues Certificate (NDC): Instant digital NOC/NDC generation when loans are fully repaid and closed.
  • Enterprise Security: 256-bit financial encryption, Laravel Passport OAuth token rotation, and Firebase OTP login.

4. cPanel / Shared Hosting Installation

Follow these detailed steps to deploy LoanX on cPanel shared or dedicated hosting:

1

Upload the Project Archive

Log in to your cPanel dashboard, navigate to File Manager, and open your domain root folder (e.g. public_html or a subdomain directory loanx.yourdomain.com). Upload the Admin panel.zip archive and extract it.

2

Crucial: Configure Document Root to /public

In cPanel, go to Domains → find your domain or subdomain → edit Document Root to append /public:

DOCUMENT ROOT EXAMPLE
/home/username/public_html/public
This protects sensitive Laravel directories like .env, storage, and app from public access.
3

Create MySQL Database & User

Go to MySQL Database Wizard in cPanel:

  • Create database name (e.g., username_loanx)
  • Create database user and generate a secure password
  • Grant ALL PRIVILEGES to the user on this database
4

Import Database or Run Web Installer

Open phpMyAdmin in cPanel → select your database → click Import → choose loanx.sql provided in the root folder, and click Go. Alternatively, visit your domain URL in the browser to run the graphical installer.

5

Update .env Configuration

In File Manager, ensure hidden files are visible (Settings → Show Hidden Files). Edit the .env file in your root folder:

.ENV CONFIGURATION
APP_NAME=LoanX
APP_ENV=production
APP_KEY=base64:NaQto7v4E0OM/x5Z4Ph0U26dRtDY5V3/moojyP1LaeI=
APP_DEBUG=false
APP_URL=https://loanx.yourdomain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=username_loanx
DB_USERNAME=username_loanxuser
DB_PASSWORD=your_strong_password
6

Verify Directory Permissions

Ensure the following folders have write permissions (775 or 755):

  • storage/ (and all subfolders)
  • bootstrap/cache/
5. VPS / Ubuntu Linux Deployment

For high-throughput, high-concurrency production deployments, follow the complete Nginx + PHP 8.2-FPM + MySQL setup commands below on an Ubuntu 22.04 / 24.04 server:

Install PHP 8.2, Nginx, MySQL & Composer

UBUNTU BASH SCRIPT
# 1. Update OS and add ondrej/php PPA
sudo apt update && sudo apt upgrade -y
sudo apt install software-properties-common curl git unzip -y
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update

# 2. Install PHP 8.2 and required extensions
sudo apt install -y php8.2 php8.2-fpm php8.2-mysql php8.2-curl php8.2-gd \
php8.2-mbstring php8.2-xml php8.2-zip php8.2-bcmath php8.2-soap php8.2-intl

# 3. Install Nginx and MySQL Server
sudo apt install -y nginx mysql-server

# 4. Install Composer globally
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

Create Nginx Server Block: /etc/nginx/sites-available/loanx.conf

NGINX CONFIGURATION
server {
    listen 80;
    server_name loanx.yourdomain.com;
    root /var/www/loanx/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php index.html;
    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_read_timeout 300;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Enable the site and issue free SSL using Certbot:

CERTBOT SSL
sudo ln -s /etc/nginx/sites-available/loanx.conf /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d loanx.yourdomain.com

Deploy Project & Execute Artisan Commands

LARAVEL DEPLOYMENT COMMANDS
cd /var/www/loanx

# Set correct ownership
sudo chown -R www-data:www-data /var/www/loanx
sudo chmod -R 775 storage bootstrap/cache

# Install production dependencies

php artisan route:cache
php artisan view:cache
6. Automated Cron Jobs & Queue Workers

LoanX includes background scheduled tasks that automatically calculate everyday overdue interest, send push notification alerts for impending due dates, and run e-NACH auto-debits.

1. Configure Laravel Task Scheduler

Run crontab -e (or configure in cPanel → Cron Jobs):

CRONTAB ENTRY (EVERY MINUTE)
* * * * * cd /var/www/loanx && php artisan schedule:run >> /dev/null 2>&1

2. Supervisor for Background Queues

Create a Supervisor daemon file at /etc/supervisor/conf.d/loanx-worker.conf:

SUPERVISOR CONFIGURATION
[program:loanx-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/loanx/artisan queue:work --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/loanx/storage/logs/worker.log
stopwaitsecs=3600

Start the supervisor worker:

sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start loanx-worker:*

4. Generate Release Keystore & Configure Signing

Run the following command in terminal to create a 2048-bit RSA release signing key:

KEYTOOL GENERATION COMMAND
keytool -genkey -v -keystore loanx-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias loanx

Place loanx-release.jks in User app/android/app/ and create User app/android/key.properties:

USER APP/ANDROID/KEY.PROPERTIES
storePassword=your_keystore_password
keyPassword=your_key_password

storeFile=loanx-release.jks

10. Troubleshooting & Common Questions

1. API returns 404 Not Found

Cause: Your web server is not routing requests through Laravel's index.php.

  • Apache: Ensure mod_rewrite is enabled (sudo a2enmod rewrite) and AllowOverride All is configured in your Apache configuration.
  • Nginx: Confirm that your server block has try_files $uri $uri/ /index.php?$query_string;.

2. HTTP 500 Internal Server Error

Check the latest error log at storage/logs/laravel.log. Typical causes:

  • Missing application encryption key: run php artisan key:generate.
  • Storage permissions: execute chmod -R 775 storage bootstrap/cache.
  • Incorrect database password in .env.

3. Uploaded Images / KYC Documents Show as Broken Links

Execute the storage symlink artisan command:

php artisan storage:link

4. Token Expiration on Mobile App

LoanX personal access tokens are configured with long-lived 365-day lifespans in AuthServiceProvider.php to avoid unexpected session drops during active loan tenures.
